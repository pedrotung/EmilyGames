# Meow Brigade (design, not built yet)

Auto-battle game: up to 5 cats in a formation fight waves of rats; tap a hurt cat to use a Nurse heal. Win coins, spin for new cats.

- `stats-table.md`: all cat and rat numbers, levels and coins (version 2, the current one)
- `cats-spec.md`: every cat's ability
- `rats-plan.md`, `balance-plan.md`: earlier rat and balance drafts (numbers replaced by stats-table.md)
- `design/`: mockups and attack animations
- `assets/`: sprites cut from Jason's drawings
- `src/`: Jason's original sheets and the scripts that cut sprites, draw mockups and run the balance simulation
